# Seguridad y configuración local

Este repositorio no contiene contraseñas, tokens, certificados privados ni archivos de configuración local.

Para ejecutar las pruebas que crean usuarios, define la variable de entorno `GUARDIAN_TEST_PASSWORD` con
una contraseña temporal de pruebas que no se use en ningún servicio real. No la escribas en el código ni la
subas al repositorio.

Las rutas del SDK de Android y Flutter se configuran localmente mediante `local.properties`, archivo excluido
por `.gitignore`.
